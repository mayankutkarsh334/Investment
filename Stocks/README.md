# Stock Investment Study

## Goal
Select the best momentum stocks per sector for **swing trades**, using the same structured screening + deep study approach as the mutual fund research.

## Approach
A structured, data-driven process — same framework as the FlexiCap mutual fund study:
1. **Sector deep study** — study all 13 sectors through 5 phases (identity, quantitative health, macro/policy/cycle, scorecard, ranking) → select top 3–4 sectors
2. **Stage 1 screening** — within selected sectors, hard filters eliminate unsuitable stocks (market cap, volume, Sharpe, age, price)
3. **Stage 2 screening** — momentum quality gates (1Y return vs peers, 200D SMA trend, momentum rank)
4. **6-module deep study** — score each shortlisted stock 1–5 across momentum, risk, technicals, fundamentals, valuation, governance
5. **Decision tree** — comparative scorecard + final pick per sector

## Universe
- Total stocks in Tickertape data (as of May 2026): **5,698 stocks** across **153 sub-sectors**
- Grouped into **13 macro-sectors** for study
